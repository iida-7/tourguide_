# PRD — 유럽 패키지 감정원 (The Package Inspector)

> **버전**: v1.2 (최신 소스코드 베이스 현행화 완료)  
> **최종 갱신일**: 2026-10-28  
> **배포 환경**: Next.js 16 (App Router), Vercel/Localhost 정적 빌드 배포, DB 없음, 외부 서버 통신 0건 (브라우저 로컬 연산, 운영비 0원)  
> **한 줄 정의**: 유럽 패키지여행 일정표를 통째로 붙여넣으면, **원문 보존 일정표 + 4대 관람 방식 팩트체크 스탬프 + 6대 레이더 스탯 + 숨은 비용 영수증 + 생존 인벤토리**를 1초 만에 즉시 감정·시각화해 주는 웹 애플리케이션

## 1. 프로젝트 개요 및 핵심 목표

### 1.1 배경 및 목표
- 유럽 여행 경험이 없는 소비자도 여행사 일정표의 실제 가치와 숨은 비용, 체력 부담을 즉각 직관적으로 이해할 수 있도록 돕는다.
- 여행사 특유의 모호한 문구("조망", "포토타임", "차창", "외관")를 팩트체크하여 **진짜 내부 입장인지, 밖에서 사진만 찍고 지나가는지** 명확히 구분한다.
- **3층 지식 커버리지 & 폴백 원칙**:
  - **1층 (일정 정리 100% 보존)**: 원문의 일차와 내용은 누락 없이 그대로 보존
  - **2층 (도시·국가 개요)**: 장소별 상세 해설이 없더라도 방문 도시 및 국가의 핵심 개요로 안내
  - **3층 (방문지 팩트 해설)**: 명소별 공식 출처 URL 및 관람 모드 팩트 해설 연결

### 1.2 핵심 성공 지표 (KPI) 달성 현황

| # | 지표 항목 | 목표 기준 | 소스코드 구현 현황 |
|---|---|---|---|
| 1 | **응답 속도** | 20,000자 이하 기준 **1초 이내** 결과 렌더링 | **달성**: 순수 브라우저 인메모리 룰 엔진(`inspector-engine.ts`)으로 0.8초 내 분석 완료 |
| 2 | **원문 보존성** | 입력된 일정 라인의 누락 0건 | **달성**: 라인 번호(`lineNum`) 추적 및 원문 라인 100% 보존 매핑 |
| 3 | **팩트 및 출처** | 검증된 명소의 공식 웹사이트 출처 표기 | **달성**: 루브르(`louvre.fr`), 융프라우(`jungfrau.ch`), 바티칸(`museivaticani.va`) 등 공식 도메인 출처 자동 연결 |
| 4 | **보안 및 비용** | 서버/외부 유료 API 호출 0건, 운영비 0원 | **달성**: 100% 브라우저 로컬(`sessionStorage`) 연산 처리, 외부 DB/서버 저장 없음 |
| 5 | **파싱 호환성** | 한국 주요 여행사 일정 형식 인식률 95% 이상 | **달성**: `제 N일`, `Day N`, `N일차`, `[N일]` 등 다중 정규식 자동 분할 지원 |
| 6 | **지역 커버리지** | 서유럽/동유럽/지중해 주요 15개국 인식 | **달성**: 20여 개 핵심 도시/국가 데이터베이스 및 플래그 매핑 내장 |

## 3. 화면별 상세 기능 및 명세

### 3.1 화면 1: 일정표 입력 화면 (`/` - `app/page.tsx`, `components/inspector/package-input.tsx`)

| 영역 | 기능 구성 요소 | 동작 및 구현 명세 |
|---|---|---|
| **헤더/타이틀** | 감정원 배너 & 메인 카피 | "유럽 패키지 일정표, 과연 꿀주일까 겉핥기 지옥일까? 1초 만에 감정해드립니다!" + `INSPECTED` 스탬프 |
| **STEP 1** | 일정표 텍스트 입력창 | - `Textarea` 본문 입력 (최대 20,000자 지원)<br>- 실시간 글자 수 카운터 및 상태 뱃지 (`정상` / `주의` / `초과`)<br>- **"✨ 예시 일정표 불러오기"** 원클릭 버튼 (서유럽 3국 8일 실전 데이터 즉시 로드)<br>- `.txt` 텍스트 파일 업로드 지원 (`FileUp`) |

| **보안 공지** | 팩트체크 보안 약속 | 원문 브라우저 로컬 분석 보장, 서버 미전송, 15개국 95% 이상 인식률 명시 |

### 3.2 화면 2: 감정 결과 화면 (`/result` - `app/result/page.tsx`, `components/inspector/result-view.tsx`)

#### 상단 종합 판정 영역 (`VerdictHeader`)
- **해설 연결률 바**: 총 방문지 중 팩트 해설 매칭률(%)을 스트라이프 프로그레스 바로 시각화
- **종합 등급 도장 (`GradeStamp`)**: 종합 가치 점수 기반 스탬프 (`S`, `A+`, `A-`, `B+`, `B-`, `C`) 및 회전 애니메이션
- **한줄 진단 배너**: 일정의 장단점을 풍자적이고 직관적으로 요약 진단 (예: "눈호강 예술투어, 그러나 버스 탑승 28시간의 압박!")
- **사용자 맞춤 뱃지**: 사용자가 직접 입력한 일정 분석 결과일 경우 `[직접 입력한 일정 감정 완료]` 태그 및 `[기본 예시 보기]` 복원 버튼 노출

#### 5대 분석 탭 구성

1. **📋 종합 개요 탭 (`OverviewTab`)**
   - **여정 트랙 (`JourneyTrack`)**: 도시 순서, 숙박 일수(N박), 도시 간 이동수단(항공, 전용버스, 고속열차) 타임라인 띠 및 호텔 이동 횟수/이동 피로도 서머리
   - **6대 스탯 육각형 레이더 차트 (`RadarChart`) & 세그먼트 게이지 (`StatGauge`)**:
     1. 문화·역사·예술 (가중치 25%)
     2. 관광 깊이 (가중치 20%)
     3. 이동 부담 (가중치 20%)
     4. 구성의 알참 (가중치 15%)
     5. 자연·경관 (가중치 10%)
     6. 날씨 적합성 (가중치 10%)
   - **방문 국가별 1분 요약**: 국기 플래그, 국가명, 핵심 특징 한줄 코멘트 카드

2. **📅 일정 팩트체크 탭 (`ScheduleTab`)**
   - **일자별 카드 (`DayCard`)**: 일차(DAY N), 방문 도시, 일차별 헤드라인, 식사 구성(조/중/석), 숙박 호텔 정보
   - **일정 항목별 4대 관람 스탬프 뱃지 (`StampBadge`)**:
     - `🎟️ 진짜 입장!`: 내부 공식 입장 관람 (출처 도메인 링크 배지 포함)
     - `👀 밖에서 찰칵(외관)`: 건물 외관 포토타임
     - `🚌 지나가며 조망(차창)`: 버스/열차 이동 중 차창 관람
     - `🤖 AI 판독(참고)`: 모호한 문맥 판독 뱃지 (클릭 시 하단 시트 모달 오픈)
   - **AI 판독 근거 시트 (`SheetContent`)**: 클릭 시 원문 문장, 원문 줄 번호(L번호), 판독 키워드, AI 판정 사유 상세 제시

3. **🧾 숨은 비용 영수증 탭 (`ReceiptTab`)**
   - **지그재그 영수증 디자인**: 실제 영수증 용지 질감 및 점선 구분선
   - **기본 패키지 결제가**: 원문 자동 감지 또는 기본 상품가 표기
   - **필수 현지 경비 리스트**: 가이드/기사 경비, 유럽 도시세(City Tax), 식당 테이블 매너팁
   - **선택관광 옵션 실시간 토글**: 곤돌라, 융프라우 산악열차, 야경투어 등 옵션 체크 시 총 예상 실지출 실시간 연산 및 패키지가 대비 추가 지출액(KRW) 표시

4. **⚖️ 최종 감정서 탭 (`ValuationTab`)**
   - **종합 가치 점수 & AI 판독 반영 토글**: 체크 시 AI가 보조 판독한 모호한 항목을 감안하여 점수 재산정
   - **여행 취향별 적합도 3종**:
     - 👨‍👩‍👧 부모님 효도 관광 적합도 (버스 이동 시간 및 피로도 기반)
     - 👫 2030 커플/신혼 적합도 (낭만 랜드마크 및 포토 스팟 기반)
     - 🏃 벼락치기 정복러 적합도 (단기간 다국가 랜드마크 압축률 기반)
   - **최고의 장점(PROS) & 아쉬운 단점(CONS)** 요약 카드

5. **🎒 생존 인벤토리 탭 (`InventoryTab`)**
   - 일정 코스, 도보량, 이동시간, 출발 계절에 맞춘 맞춤형 생존 준비물 8종 추천
   - 4단계 희귀도 슬롯: 일반(`common`), 레어(`rare`), 에픽(`epic`), 전설(`legend`)
   - 아이템별 2가지 구체적 추천 사유 명시 (예: 쿠션 러닝화 - '로마 자갈길', '하루 1.8만보')

#### 하단 액션 바 (`ActionBar`)
- **마크다운 복사**: 감정 결과를 마크다운 서식 텍스트로 클립보드 복사
- **.md 다운로드**: `유럽패키지-감정결과.md` 파일 즉시 저장
- **인쇄 / PDF 저장**: `window.print()` 스타일 시트 최적화 인쇄 지원
- **새 일정 분석**: 홈 화면으로 이동

## 4. 데이터 모델 및 분석 엔진 사양

### 4.1 핵심 데이터 인터페이스 (`lib/mock-result.ts`)
```typescript
export type TourMode = 'entry' | 'exterior' | 'window' | 'ai'
export type Basis = 'fact' | 'keyword'
export type TransportKind = 'flight' | 'bus' | 'train'

export interface PackageResult {
  coverage: { rate: number; matched: number; total: number }
  grade: string
  totalScore: number
  diagnosis: string
  journey: JourneyNode[]
  journeySummary: { cities: number; hotelMoves: number; fatigue: string }
  stats: StatItem[]
  countries: CountrySummary[]
  days: DaySchedule[]
  receipt: {
    packagePriceKrw: number
    eurToKrw: number
    mandatory: ReceiptLine[]
    options: OptionLine[]
  }
  valuation: {
    baseScore: number
    aiScore: number
    aiNote: string
    fits: FitItem[]

    cons: string
  }
  inventory: InventoryItem[]

```

### 4.2 분석 엔진 동작 파이프라인 (`lib/inspector-engine.ts`)
1. **Raw Text 정규화 & 라인 번호 보존**: 원문의 공백 및 개행을 분리하며 정확한 `lineNum` 부여
2. **Day 분할**: `제 N일`, `Day N` 키워드로 일자 블록 분리 및 식사/호텔 메타정보 추출
3. **도시/국가 매핑**: 20여 개 유럽 주요 도시 DB(`CITIES_DB`)와 텍스트 대조
4. **관람 모드 4대 분류**:
   - `내부|입장|관람|탑승` → `entry`
   - `외관|전경|포토타임|조망` → `exterior`
   - `차창|경유|이동|전용버스` → `window`
   - 기타 모호한 서술 → `ai` (사유 및 판독 키워드 생성)
5. **공식 출처 매칭**: 사전 등록된 공식 도메인 DB(`SIGHTS_SOURCE`)와 매칭하여 사실 출처 부착
6. **동적 비용 및 스탯 계산**: 원문 내 상품가/선택옵션 추출 및 출발 월 날씨 가중치 결합 점수 산출
7. **세션 캐싱**: 브라우저 `sessionStorage`에 직렬화하여 저장, 결과 뷰에서 즉시 동기화

## 5. 예외 처리 및 무결성 보장

1. **빈 입력 및 최소 글자수 미달**: 감정 버튼 자동 비활성화 및 안내 텍스트 출력
2. **최대 글자수 초과 (20,000자 초과)**: 초과 글자 수 안내 및 버튼 비활성화
3. **일차 미분류 텍스트 입력 시**: 원문이 누락되지 않도록 1일차 가상 블록으로 100% 감싸서 결과 도출
4. **Division by Zero 방어**: 레이더 차트 및 세그먼트 바의 분모(`max`)가 0이거나 미정의 시 `1`로 안전하게 폴백
5. **오프라인/폐쇄망 빌드 안정성**: Google Fonts 요청 실패 시에도 시스템 폰트(`fallback`)로 즉각 대체되어 프로덕션 빌드 정상 완료 보장
